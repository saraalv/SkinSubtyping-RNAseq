# SkinSubtyping-RNAseq
Clasificación de subtipos de cáncer de piel mediante datos de RNA-seq

Este repositorio contiene el desarrollo y evaluación de distintos modelos de aprendizaje automático para la clasificación de subtipos de cáncer de piel a partir de datos de expresión génica obtenidos mediante RNA-seq.

Se implementan y comparan diferentes algoritmos de clasificación, incluyendo Support Vector Machines (SVM), Random Forest, redes neuronales artificiales, k-Nearest Neighbors (k-NN), Naive Bayes y árboles de decisión. El objetivo es evaluar su capacidad para identificar y discriminar diferentes subtipos de cáncer a partir de sus perfiles transcriptómicos.

El repositorio incluye el procesamiento y preparación de los datos de RNA-seq, entrenamiento de los modelos, evaluación de su rendimiento y comparación de los resultados obtenidos mediante diferentes métricas de clasificación.
